# GitLab Jira Label Sync

> **Sở hữu bởi Hoàng Mạnh Phú**

> **Lưu ý:** Extension này được tạo với mục đích dành cho công việc cá nhân.

Chrome extension tự động đồng bộ labels từ Jira tickets sang GitLab merge requests.

## Tính năng

- Đồng bộ labels từ Jira tickets sang GitLab merge requests
- Hỗ trợ GitLab branches và epics
- Tùy chỉnh cấu hình qua trang Options

## Cài đặt

1. Clone repository này
2. Mở `chrome://extensions/` trên Chrome
3. Bật **Developer mode**
4. Chọn **Load unpacked** và trỏ đến thư mục của extension

## Sử dụng

1. Cấu hình GitLab và Jira thông qua trang Options của extension
2. Mở một merge request trên GitLab — extension sẽ tự động đồng bộ labels từ Jira
