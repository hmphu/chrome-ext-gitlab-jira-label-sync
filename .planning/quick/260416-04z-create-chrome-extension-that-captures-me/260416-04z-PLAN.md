# Quick Task 260416-04z: Chrome Extension - GitLab Jira Label Sync

**Mode:** quick
**Created:** 2026-04-16
**Description:** Create Chrome Extension that captures merge request titles on GitLab pages, extracts Jira ticket IDs, fetches labels from Jira, and creates/adds matching labels to GitLab merge requests

## Task 1: Create Chrome Extension with manifest, popup UI, and core logic

**Files:**
- `manifest.json` — Chrome Extension manifest v3
- `popup.html` — Extension popup UI
- `popup.css` — Popup styling
- `popup.js` — Popup logic and orchestration
- `content.js` — Content script to extract MR titles from GitLab pages
- `background.js` — Service worker for API calls (Jira + GitLab)
- `options.html` — Options page for API credentials
- `options.js` — Options page logic
- `options.css` — Options page styling
- `icons/` — Extension icons (16, 48, 128)

**Action:**
1. Create `manifest.json` with Manifest V3, permissions for GitLab domains, storage, activeTab
2. Create `content.js` — content script that:
   - Detects GitLab merge request list pages
   - Extracts MR titles from the page DOM
   - Parses Jira ticket IDs from titles (pattern: `[A-Z]+-\d+`)
   - Sends extracted data to background script
3. Create `background.js` — service worker that:
   - Receives MR data from content script
   - Calls Jira REST API to get labels for each ticket
   - Calls GitLab REST API to create labels if they don't exist on the project
   - Calls GitLab REST API to add labels to the merge request
4. Create `popup.html/js/css` — popup that:
   - Shows "Sync Labels" button
   - Displays progress/results of sync operation
   - Shows list of MRs found with their Jira tickets and labels
5. Create `options.html/js/css` — settings page for:
   - GitLab personal access token
   - GitLab API base URL
   - Jira API base URL
   - Jira credentials (email + API token)
   - Jira ticket ID pattern (configurable regex)
6. Create placeholder icons

**Verify:**
- Extension loads in Chrome via chrome://extensions developer mode
- All files present and referenced correctly in manifest

**Done:**
- Chrome Extension with full Jira-to-GitLab label sync functionality
- Options page for credential configuration
- Popup UI showing sync status and results
